Mitumba Pay

Africa-native payment SDK — M-Pesa, Airtel Money, card, and more, behind one provider-neutral client.

Install

npm install @mitumba/pay

Core principle

You choose a method (mobile_money or card). The backend chooses the provider. Provider identifiers are observable metadata, never routing choices — the backend can add MTN MoMo, Vodacom, Paystack, etc. without an SDK release. Always follow next_action; never branch on a provider switch.

Quick start

import { MitumbaPay } from '@mitumba/pay'

const pay = new MitumbaPay({ token: () => getAccessToken() })

const { next_action } = await pay.initiateCheckout({
  order_id: 'ord_123',
  idempotency_key: crypto.randomUUID(),
  method: { type: 'mobile_money', phone: '+254712345678' },
})

if (next_action.type === 'redirect') {
  window.location.href = next_action.url
}

const final = await pay.pollCheckoutStatus('ord_123', {
  onUpdate: (s) => console.log(s.checkout_status),
})

Checkout status

Poll getCheckoutStatus(orderId) after initiation. It honors server-authored poll_after_ms (with jitter), stops on terminal, and reports retryable. Amounts are integer minor units (KES 1,250.00 === 125000).

Note: initiateCheckout targets POST /pay/checkout/initiate, whose backend route may be pending deployment in some environments. Verify before production use. getCheckoutStatus is live.
